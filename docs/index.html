Maestro

O modelo caro planeja. O barato executa.

Plugin gratuito e aberto para Claude Code que quebra seu projeto em blocos, decide o quanto cada um é arriscado e manda cada um para o modelo certo — com critério de aceite verificável por teste, não por opinião do modelo.

O que é

Três decisões que o Maestro toma por você, todas as vezes, do mesmo jeito.

01

Classifica por complexidade

Cada bloco recebe uma nota de C1 a C5 pela decisão que o executor precisa tomar sozinho — não pelo tamanho — e vai para o modelo mais barato que dá conta.

02

Revisor independente

Quem escreve não aprova. O revisor roda em sessão separada, sem permissão de editar arquivo, e confere critério por critério com evidência.

03

Multi-agente real

Memória persistente, handoff tipado entre agentes, protocolo agnóstico de harness e SDK de adapters. Não é um wrapper de prompt.

Camadas

Cinco camadas isoladas. Use as que precisar — os comandos do dia a dia não exigem nenhuma configuração.

🧠
Memory Working, Episodic, Semantic e Procedural Memory com índice SQLite — o agente lembra entre sessões.
⚡
Providers Roteamento usage-aware e capacity-aware, com telemetria CEV (custo-eficiência-velocidade) por provider.
🤝
Handoff Transferência tipada entre agentes, com semântica exactly-once e workstreams sob lease exclusivo.
📦
Protocol Universal Context Packet (UCP) e Universal Event Protocol (UEP) — contratos agnósticos de harness.
🔌
Adapter SDK Manifests, conformance suite e GenericCLI — qualquer ferramenta de linha de comando vira adapter.

Instalar

Três comandos dentro do Claude Code. Nada sai da sua máquina.

/plugin marketplace add torvik/Maestro/plugin install maestro@maestro/maestro:setup

O /maestro:setup detecta o que já existe no repositório, faz até seis perguntas e gera o plano — que você lê e corrige antes de qualquer linha ser escrita.
