# Maestro

O modelo caro planeja. O barato executa.

Plugin gratuito para Claude Code. Veja [plugins/maestro/README.md](plugins/maestro/README.md) para detalhes, e [plugins/maestro/INSTALACAO-USUARIO.md](plugins/maestro/INSTALACAO-USUARIO.md) para instalar.

## Instalar

```
/plugin marketplace add SEU-USUARIO/maestro
/plugin install maestro@maestro
```
